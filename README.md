# pcmedicalist-retrobyte-media

Public media host for RetroByte social videos. Served via GitHub raw / `github.io`
so Buffer can fetch video URLs for posting to X / Instagram / TikTok.

This repo contains **only video files** — no source code, no secrets, no `.env`.

## Layout
- `media/*.mp4` — RetroByte clips (854x480, 5s)

Videos are mirrored from the private `pcmedicalist-retrobyte` repo's `media/` folder.
